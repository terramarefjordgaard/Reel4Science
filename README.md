# Reel4Science – ACCESS-Fjord data hub

**ACCESS-Fjord** is a [Terramare](https://terramarefjordgaard.odoo.com/) project connecting recreational fishing,
citizen science and marine research in Sørfolda, Northern Norway.

The visitors of the Terramare fish-camp take part in the scientific monitoring of the fjord: they go on fishing
trips and record their catches with the Reel4Science app. This website gathers those data as they are produced
at sea:

- a map of the monitoring stations, with what was caught at each one;
- for each species, the catches over time and the relation between length and weight;
- a leaderboard of the community, with a Biodiversity Prize and a Conservation Prize.

The website updates itself: while it is open, new trips and catches appear within a few minutes.
